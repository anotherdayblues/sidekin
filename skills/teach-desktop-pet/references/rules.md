# 规则写法

学会的动作什么时候做，只有三种（plan/29）：**双击时**、**随机出现**、**每天定时**（可只在工作日）。一个动作可以同时有这几种，每种写一条规则。完整限制见 [teaching-contract.json](teaching-contract.json)。

```json
{ "id": "night-pillow", "label": "晚上抱枕头出来",
  "when": { "type": "clock", "at": "23:00" },
  "do": [{ "play": "pillow-walk" }] }
```

- `id`：小写字母、数字、连字符。同一个 `id` 会替换旧规则。
- `label`：给用户看的短说明，不超过 40 字。
- `do`：只有一步，播一个**这次或以前学会的动作**一次。不写 `repeat`、`wait`，不用基础动作，不用睡觉。一串连贯的表演做成一个动作。
- 不写 `chance`、`cooldownMinutes`。
- 随机出现的 `weight` 是**每小时大约几次**：偶尔 6（约 10 分钟一次）、有时 20（约 3 分钟一次）、常常 40（约 1 分半一次）。用户没说多常见就用 20。

随伴和脚本都会拒收别的写法。用户在随伴首页动作的设置键里也能随时改这三种。

## 触发条件对照

| 用户可能这样说 | `when` |
| --- | --- |
| 双击它 | `{"type":"event","event":"double-click"}` |
| 偶尔 | `{"type":"random","weight":6}` |
| 时不时 / 随机做 | `{"type":"random","weight":20}` |
| 经常 | `{"type":"random","weight":40}` |
| 晚上 11 点 / 每天 23:00 | `{"type":"clock","at":"23:00"}` |
| 工作日早上 9 点 | `{"type":"clock","at":"09:00","days":[1,2,3,4,5]}` |

- **双击只给一个动作。** 已经有动作在双击上时，新的会替换它；复述计划时说出来。
- **`clock` 的补触发**：到点时电脑在睡眠或宠物正忙，30 分钟内会补上；过了就跳过当天这一次。
- **别的时机都不支持**：单击、拖动、放下、悬停、出现时、专注开始或完成、休息开始、没碰宠物几分钟、电脑闲置、连续工作、每隔多久、每个整点。这些时候宠物做自己的基础动作，不能替换。用户这样说时，说明现在只支持三种，建议最接近的一种：“每隔一小时”“工作久了”改成随机出现，“每个整点”改成每天定时的某个时间。

## 例子

“偶尔打个滚”：

```json
{"id":"roll","label":"偶尔打滚","when":{"type":"random","weight":6},"do":[{"play":"roll-over"}]}
```

“双击它就伸懒腰，工作日早上 9 点也伸一个”：

```json
{"id":"double-stretch","label":"双击伸懒腰","when":{"type":"event","event":"double-click"},"do":[{"play":"stretch"}]}
{"id":"morning-stretch","label":"早上伸懒腰","when":{"type":"clock","at":"09:00","days":[1,2,3,4,5]},"do":[{"play":"stretch"}]}
```

## 按结束方式选择动作

先看用户这次的描述和前面已经说清的要求，判断这一次动作怎样才算做完。同一个名字可以有不同做法。结束方式已经明确时，直接按要求制作。

| 用户想要的结果 | 制作方式 |
| --- | --- |
| “抬头看一眼星星就回来” | 做一次普通动作，播完自然结束。规则只写 `play`。 |
| “挥三次手” | 把三次挥手画进同一个动作。规则不写 `repeat`。 |
| “一直看星星，直到我点它” | 做持续动作，用 `loopFrames` 标出中段。收到结束请求后，播完当前循环再收尾。 |

“每天晚上十点”说明何时开始，“偶尔”说明出现频率，两者都不能决定单次动作怎样结束。只有结合上下文仍有两种合理做法，而且会影响素材或规则时，才问一句具体的问题，例如：“你想让栗子看一眼就回来，还是一直看，等你点它再回来？”

已有动作沿用动作包原来的设置。没有 `loopFrames` 的动作继续按普通动作播放。只有用户要求改变结束方式时，才修改相应的动作或规则。

## 制作可以一直持续的动作

睡觉、画画、看星星可以做成持续动作。先确定中间的共同姿势，再制作进入、中间循环和退出三段。同一段里可以有几个姿势。三段共用画布、尺寸和落脚点。循环要有真实变化，例如胸背抬起再落回去，脚掌始终贴地。

把三段按顺序排进最终横条。在原有的 `add-action` 命令上加 `--loop-frames 5 12`，表示第 5 至 12 帧循环，编号从 1 开始且包含两端。按实际素材填写。前后各留至少一帧，中间至少两帧。持续动作在桌面点宠物后播完当前循环，再播放退出段。

检查脚本生成的 GIF，确认进入、中间连续三轮、退出三个接缝。再用随伴的展台试播，在循环中途点宠物。看清收尾后再交给用户决定是否接受。
