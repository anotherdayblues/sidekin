---
name: find-pet-tool
description: 给随伴挑一个能查资料的只读工具。用户问“你觉得我需要什么工具”、想添加某种查询能力或明确提到 find-pet-tool 时使用。
---

先问用户希望宠物帮自己查什么。说不清时，读同目录的 [工具清单](catalog.json)，举两三个接近日常生活的例子。只推荐清单中实际匹配的工具，说明用途、哪些内容发给谁、是否需要账户或 Key。没有合适的就说“现在还没有”，指出相近选择和区别。

用户明确同意接收某项后，用当前技能目录里的 Python 脚本投递，把一句简短的申请理由传给它，用用户说话的语言（中文或英文）。理由只写用途，不要包含用户的实际问题、网址、数字、账户或密钥。需要凭据时让用户在随伴里填。沿用用户给出的 PET_STUDIO_DATA 以投递到相应试玩版。

    python3 scripts/tool_card.py send 工具编号 "用于查公开资料。"

queued 表示已投递、等待随伴打开；received 表示随伴收到了草稿。只有 enabled 才是已启用；discarded 表示用户已放弃。要核对之后的决定，执行下列命令，传入首次回执中的投递编号：

    python3 scripts/tool_card.py status 投递编号
