# 双参考图提示词规范

制作新衣服的核心原则是「换衣不换宠、动作跟原宠、尺寸锁死不拉伸」。

## 1. 两阶段双参考结构

1. **阶段一：定妆（`base`）**
   - 参考图：`refs/base-idle-0-2x.png`（原宠物的待机第 0 帧）。
   - 目标：让原宠物穿上 `--desc` 描述的新衣服，严格保留原宠物种、头身比例、脸部五官、毛色花纹和自然站姿。
   - **必须先给用户看并确认**，不要跳过定妆直接画动作。

2. **阶段二：动作行与注视行（`idle` .. `review`，V2 加 `gaze-1`、`gaze-2`）**
   - 每次生图必须同时附带**两张参考图**：
     1. `approved/base.png` —— 锁定新衣服的颜色、款式、配饰与宠物身份。
     2. `refs/rows/<job>.png` —— 锁定该行每一帧的姿态、步态、跳跃高度、朝向和注视角度。
   - `jobs/<job>.txt` 已写清帧数、等宽横排、留出明确空隙和色键背景要求，直接作为提示词传给生图工具即可。

## 2. 自动避色（Chroma Key Selection）

脚本在 `init` 时会扫描 `--desc` 里的中英文颜色词，自动避开与衣服撞色的背景色：
- 衣服含绿/薄荷/抹茶/橄榄/森林绿等 → 避开 `#00FF00`，改选品红 `#FF00FF` 或青色 `#00FFFF`。
- 衣服含粉/紫/红/玫红/薰衣草等 → 避开 `#FF00FF`，改选亮绿 `#00FF00` 或青色 `#00FFFF`。
- 衣服含蓝/青/牛仔/藏青/冰蓝等 → 避开 `#00FFFF` 和 `#0000FF`，优先选 `#FF00FF` 或 `#00FF00`。

提示词里必须要求「flat pure `<chroma_name> <chroma_hex>` background」，不要让生图模型直接画透明棋盘格、阴影、地面或发光特效。

## 3. 自然比例与锚点锁定

- **不要强行拉大角色填满格子。** 保持原宠物原本的自然留白和头身比例。
- `dress.py accept` 会读取 `refs/anchor.json`，把每一行严格缩放到与原宠同一行完全一致的像素身高和落脚点 Y 坐标，确保用户在随伴里切换衣服时不会出现「变大、变小或上下跳一下」。
- 如果生图模型把相邻两帧画粘在一起导致自动切帧失败，优先重新生成让相邻姿势留出清晰背景空隙；只有确认原图各姿势确实严格等宽居中时，才在 `accept` 时附加 `--equal-slots`。

## 4. 睡眠横条（`sleep`）高清制作与验收

适用于**新做整套衣服附带睡眠**以及 **`--only-sleep` 单独补睡眠**（其余标准动作行照旧）：

1. **双参考与大图画法（禁止一张宽图硬挤 16 帧）**：
   - 同时参考 `approved/base.png`（确认的新衣服）与 `refs/rows/sleep.png`（原宠睡眠动作）。
   - 首尾帧（第 1 帧、第 16 帧）直接复用已通过的穿衣待机帧；入睡过渡与入睡定格的关键姿势单独画大图，裁掉留白后角色自身宽高建议至少达到最终显示尺寸的 **2 倍**，再统一缩小拼进 16 格 `3072×208`（每格 `192×208`），用 `--equal-slots` 传给 `dress.py accept`。
   - 呼吸循环段沿用原宠的 `loopFrames`（1 起始闭区间），**共用同一张定格睡姿图**，只让局部做轻微呼吸起伏；头部、五官、衣领与静止/贴地锚点保持位置固定，零横向位移。
2. **选色与先抠后缩**：
   - 对照参考图里角色、衣服和配饰的实际颜色，选一个都不撞色的纯色 `#RRGGBB`（若默认避色有冲突则显式改选），生图与抠图使用同一个色值。
   - **在高清原稿上先抠透明再缩小**：沿用换装技能的边界连通去底 + 外缘去色边处理，保留细线（如胡须）与半透明边缘，严禁整图按颜色删除；单独检查腿间、尾巴圈里、领口下等封闭空隙是否残留底色。
3. **验收与交付**：
   - 把睡姿和穿衣待机按**桌宠实际大小**并排对比清晰度与细节，再分别放到**浅底与深底**上检查有无残色、破洞或缺边。
   - 连续播放 **3 轮呼吸再接起身**（`qa/sleep.gif`），逐帧确认静止/贴地锚点横向位移为 0 像素、呼吸起伏清晰自然、循环接头无跳变。
   - 新做整套衣服时，睡眠条随服装图集一起交付；使用 `--only-sleep` 补睡眠时，只增量交付这套衣服的睡眠横条。
